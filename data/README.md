# Data

- `raw/alzkb/`: official AlzKB v2.0.0 CYPHERL dump and metadata.
- `raw/evo2/ad_all_scores_v3_vcf.csv`: Evo2 wild-type/mutant score table.
- `raw/clinvar/`: source GRCh38 ClinVar tables and skipped-record audit.
- `processed/variants_with_uncertainty.csv`: cached 985-variant,
  graph-matched table used by the paper run.
- `manifest.json`: SHA-256 provenance checksums.

Raw data are not distributed with this repository; see the top-level README
for download instructions. Do not edit files under `raw/`.
